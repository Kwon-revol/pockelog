# PockeLog 설정 탭 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 로그인 사용자가 현재 장부의 이름과 정산 기준일을 변경하고, 소유자 권한으로 수입·지출 분류를 생성·수정·정렬·비활성화·재활성화할 수 있는 반응형 설정 탭을 구현한다.

**Architecture:** Next.js 서버 컴포넌트가 현재 사용자의 기본 장부, 구성원 역할, 활성·비활성 분류를 읽는다. 서버 액션은 Zod 검증을 거쳐 로그인 사용자 세션과 기존 RLS로 변경하며, 분류 순서 변경만 새 `security invoker` RPC에서 원자적으로 처리한다. 클라이언트 화면은 장부 설정 폼과 수입·지출 분류 관리 영역을 분리하고 성공 시 새 서버 데이터를 다시 렌더링한다.

**Tech Stack:** Next.js 16 App Router, React 19, TypeScript 5, Tailwind CSS 4, Supabase PostgreSQL/RLS, Zod 4, Vitest, Testing Library, pgTAP, Playwright

**Spec:** `docs/superpowers/specs/2026-08-26-pocketlog-design.md`의 6.3, 7, 8.6, 9.1절

## Global Constraints

- 모든 수정은 `D:\myProject\pockelog\.worktrees\settings` 안에서만 수행한다.
- 이번 단계는 장부 이름·정산 기준일·분류 관리만 구현한다. 프로필·비밀번호·공동 사용자·CSV·휴지통은 후속 단계다.
- 정산 시작일은 `1~28` 또는 `null`(말일)이며 변경 직후 가계부 기본 기간과 통계 기간에 반영한다.
- 분류 이름은 trim 후 1~30자, 색상은 `#RRGGBB`, 동일 장부·유형 안에서 이름이 대소문자 구분 없이 고유해야 한다.
- 거래가 참조한 분류는 삭제하지 않고 `is_active=false`로 보존하며 기존 거래와 통계에는 계속 표시한다.
- 장부 소유자만 설정을 변경하고 일반 구성원은 읽기 전용으로 본다. 브라우저와 서버 액션 모두 서비스 역할 키를 사용하지 않는다.
- 분류 순서 변경은 모바일·PC에서 모두 키보드로 사용할 수 있는 위/아래 버튼을 제공한다.

- 장부 이름·정산 기준일·분류 생성·수정·정렬·숨김·복원을 Task 1~4에 모두 연결했다.

- 프로필·공동 사용자·CSV·휴지통은 이번 범위에서 명시적으로 제외해 후속 단계와 겹치지 않는다.
- 모든 함수·타입·검증 명령과 제외 범위가 명시되어 있다.
